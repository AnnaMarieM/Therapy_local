# AD-03: No speech migration; old speech models are wiped by hand

| | |
|---|---|
| Status | Accepted |
| Decided | `2026-11-06 16:47 CET` |
| Decided by | Martin Hajný (@hajnina) |
| Supersedes | AD-02, only its point 6 (existing installs migrate once at start-up) and the migration items in its Verification |

## Context
- AD-02 made Canary the only speech recogniser and required a one-time start-up migration: delete the `engine` and `whisper_size` settings, delete the downloaded Whisper and Parakeet folders, log `speech_engine_migrated` and `model_files_removed`.
- The app has no users. Every install is a test device that the team controls. The only installs that held the old files were two test devices (a phone and a tablet).
- The migration would be code that runs once on devices that no longer need it and then never again. It would still need a seam, a list of the old folder names and tests.

## Decision
- There is no speech migration in the app. `SpeechMigration` is not built.
- The old Whisper and Parakeet model folders are deleted by hand on the test devices. A stale `engine` or `whisper_size` setting is never read, so it does no harm.
- The dev harness (`DevHarness`) still ignores `engine` and `whisper_size` in a `job.json` and logs `dev_setting_ignored`.
- Everything else in AD-02 stands: Canary is the only speech recogniser, and Gemma speech recognition, Whisper and Parakeet code and specs are removed.

## Alternatives considered
- **Keep the migration (AD-02 as written).** Rejected: dead code once the test devices are wiped, and there are no other installs.
- **Keep the migration until the first external release.** Rejected: if an install with old files ever exists, wiping by hand costs less than carrying the code.

## Consequences
- Better: less code and fewer tests in the first commit. The grep rule becomes simple: `grep -rn -i "whisper\|parakeet\|GemmaAsr\|withAudio\|audioLlm" app/src/main` returns nothing.
- Worse: an install that still holds the old folders keeps them on disk (several GB) until someone deletes them. Nothing reads them.
- Accepted, still true while the app has no users. If it ships to anyone with old files before they are deleted, a new decision must bring a cleanup back.

## Verification
- The grep above returns nothing.
- No class named `SpeechMigration` exists, and `App.onCreate` does not call one.
