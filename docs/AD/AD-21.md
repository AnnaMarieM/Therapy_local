# AD-21: On-device GPU and NPU inference uses the same model as the CPU

| | |
|---|---|
| Status | Accepted |
| Decided | `2026-11-13 13:58 CET` |
| Decided by | Martin Hajný (@hajnina) |
| Drafted by | Claude (Sonnet), branch `worktree-frolicking-foraging-aurora` |

## What
- Phones, tablets and handhelds have unified memory: the CPU, GPU and NPU use the same RAM. There is no separate VRAM.
- So the GPU or NPU backend never needs a smaller model than the CPU backend. Pick the model once for the device's free RAM; pick the backend for speed.
- Backends are compared on the same weights and the same quantisation.

## Why
- The "the GPU needs a smaller model" rule comes from discrete GPUs with their own memory. It does not apply here.
- A smaller model on one backend mixes accuracy with speed and gives a wrong comparison.
- The real limits are free RAM and the per-app memory cap, whichever backend runs.
