## 6. Bugs found

- **Schema bump 8 to 9**: `MindStore.recreate` dropped parent tables first, so the vault could not open again. Affects any real vault upgrade. Fix on `origin/feature/quality-workflows` commit `9f10c5b`, **not reviewed**.
- **Whisper threads inherited the `:batch` background priority**, so Whisper ran far slower. Fixed in `5557d3b`. The same root cause was fixed for ORT and LiteRT in PR #106. Anything heavy in `:batch` may be throttled, so earlier on-device timings could be pessimistic.
- **`MemoryService` is `exported="false"`**, so the shell cannot start it and `qa-api.sh` must `am start` the activity first. A QA-only overlay (exported, DUMP permission, `--no-launch` path) was designed but never built or proven.
- **Duplicate AD-18**: `origin/feature/english-pivot` ("Canary stays") and `origin/fix/batch-engine-priority` (`:batch` priority policy). One needs renumbering, and AD-22 conflicts with the first.
- Gemma GPU FLOAT32 results are in PR #117 and `~/therapy-measurements/gpu-float32-2026-11-13/`. They pass on all three devices. Pixel load: 45 s awake, 325–344 s locked on battery, 68–74 s locked and charging. The Poco is unaffected by the lock screen and its NPU fails proof 2.
