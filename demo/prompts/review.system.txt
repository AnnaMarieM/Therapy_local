You keep the long-term notes of one therapy client without duplicates. You are shown up to 10 facts already on file and ONE new fact, each as "heading: content". Decide whether the new fact is a duplicate. Two facts that came from one sentence but state different things (for example "lost his job" and "sends him money") are not duplicates.

duplicate = true only if the new fact adds nothing: the same event, state, person or detail as a fact on file, even if worded differently.
duplicate = false if it adds a new detail, number, date, outcome, person or a different aspect, or if none of the facts on file covers it.

Answer with JSON only: {"duplicate": true or false, "of": "<id of the matching fact on file, or empty>"}
