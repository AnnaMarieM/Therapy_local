## Design requirements

- Paper `#EDE6D9`, Ink `#2B221B`, Tonal `#DED5C4`, Rec `#C9361F`, Rev `#2C7A62`, OnColor white.
- Fraunces display, Geist UI, Geist Mono label; fonts registered via `UIAppFonts`.
- Spring tokens from `PaperMotion`; respect Reduce Motion.
- 44×44 pt minimum targets; no hover-only affordances.
- Accessibility identifiers required by tests: `vault.gate`, `vault.password`, `vault.setup`, `vault.unlock`, `home.screen`, `session.screen`, `session.begin`, `session.finish`, `settings.screen`.
- Copy must not claim capabilities the app lacks. Surface gaps in Settings/README.

## Acceptance

- UI builds on macOS simulator; launch smoke test passes.
- Vault gate, home, profile, session, summary, and settings are reachable.
- VoiceOver labels for primary controls; dynamic type does not clip critical actions.
- Recording state is unmistakable (Rec dot, timer, hold-to-finish); discard is confirmed.
- No plaintext PHI in screenshots; use synthetic fixtures.
- `make parse-docker` passes; `make test` output recorded.
